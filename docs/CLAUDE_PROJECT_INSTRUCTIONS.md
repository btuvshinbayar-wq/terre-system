# claude.ai Project-д хуулах заавар

**Project нэр:** Terre System

**Project instructions** (Project → Instructions хэсэгт доорхыг хуулна):

---
Энэ Project бол Terre System — миний Windows дээрх хувийн AI туслах (өмнө нь "Jarvis" гэж нэрлэж байсан, одоо Terre).
Python (FastAPI) + HTML самбар, NSIS installer. Миний School Manager (Electron) програмтай Terre Bridge-ээр холбогддог.
Монголоор, товч, алхам алхмаар тайлбарла. Би мэргэжлийн хөгжүүлэгч биш — кодыг AI-аар бичүүлж өөрөө нэгтгэдэг.

Байнгын дүрэм:
- Мэйл хэзээ ч автоматаар илгээхгүй, файл хэзээ ч устгахгүй, үйлдэл бүрийг буцаах боломжтой байлга.
- School Manager-ийн лицензийн логикт хүрэхгүй. Firebase / Smart Report-той холбохгүй.
- Gemini зардлыг бага байлга (Flash-Lite ангилал, thinking унтраах).
- Шинэ UI нь одоогийн хөдөлгөөнт HUD хэв маягийг дагана.
- Код өөрчилсний дараа installer-ийг дахин бүтээх шаардлагатай эсэхийг хэлж өг.
