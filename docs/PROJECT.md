## 3. Гол шийдвэрүүд
- **Electron биш, Python + браузер/Edge app цонх** — өмнө Electron багцлахад гацаж байсан тул. Installer нь conda-forge-ийн
  Windows Python 3.12 + wheel-үүдийг NSIS-ээр багцалдаг (Linux дээр бүтээгддэг, Wine шаардлагагүй).
- **School Manager-ийг товч дарж биш, bridge-ээр** — эзэн зөвхөн **Lite (Neutralino)** хувилбар ашигладаг. Lite-д Node процесс
  байхгүй тул **файлын шуудангийн хайрцаг**: `%APPDATA%\TerreBridge\school-manager.json` (token, inbox/outbox, dataDir, heartbeat 5 сек),
  тушаал `inbox\<id>.json` → хариу `outbox\<id>.json`. Neutralino-ийн filesystem API-аар 1 сек тутам (Worker-ийн цохилтоор — minimized үед ч)
  шалгана. Порт, нэмэлт програм, config өөрчлөлтгүй. Дэлгэцийн экспортыг (тайлан, цагийн тооцоо, нэгтгэл) `useTerreView`-ээр
  дэлгэцийн өөрийн функцээс дуудна — логик давхардахгүй. Лиценз идэвхгүй бол өөрчлөлт хүлээж авахгүй.
- **Хаалттай үед файлаас унших** — `sm-data-mirror.json`-оос (config `data_dir` → bridge-ийн `dataDir` → `data-location.json`)
  самбарын тоо, жагсаалтыг уншина. Бичихгүй; лиценз, Gemini түлхүүрийг уншихгүй.
- **Зохиомол өгөгдөл байхгүй** — демо горимд School Manager-ийн өгөгдөл харуулахгүй, демо мэйлд хүний нэр зохиохгүй,
  тушаалд дутуу утгыг таамаглаж бөглөхгүй.
- **Хариу хэзээ ч автоматаар явахгүй.** Архивлах ч `auto_actions: true` үед л.
- **Нууц:** keyring (Windows Credential Manager); самбар нь токен cookie-тэй (зөвхөн TED-ийн нээсэн цонх).
- **Зардал:** сард ~3,000–5,000₮ (Flash-Lite ангилал, thinking унтраасан Flash ноорог). Gemini үнэгүй түвшин өгөгдлийг
  сургалтад ашигладаг тул эцэг эх, багшийн мэйлд **төлбөртэй түвшин** зөвлөсөн.
- Messenger, Viber-т хувийн дансны албан ёсны API байхгүй тул холбоогүй.
