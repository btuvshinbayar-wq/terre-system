# TED — Windows дээрх хувийн AI туслах

Компьютер асахад TED:
1. **Монголоор дуугаар мэндчилж**, өнөөдрийн хуваарь, мэйл, хугацаа дөхсөн ажил, тоон үзүүлэлтийг уншина
2. Gmail, Outlook, бусад мэйл (IMAP), Telegram, Google Chat-ийг шалгаад мессеж бүрийг ангилна:
   🔴 **Яаралтай** · 🟡 **Таны зөвшөөрөл хэрэгтэй** (ноорог бэлэн) · 🟢 **TED шийдсэн**
3. Мэйлээс **хугацаа, даалгавар, хурлын урилгыг** ялгаж, хурлыг календарьт нэмэх санал болгоно. Илгээсэн хариунд хариу ирэхгүй бол сануулна
4. **School Manager**-ийг удирдана: багшийн ирц, тэмдэглэл, төлөвлөгөө, тайлан, нөөцлөл
5. **Өдрийн тайлан**: 17:00-д өнөөдрийн ажлаас School Manager-ийн тэмдэглэлийн ноорог бэлдэнэ
6. **Файл**: хавсралт татаж нэрлэнэ, хавтсуудыг цэгцэлнэ, **файл дотроос хайж, асуултад хариулна**
7. **Утаснаас удирдах** (Telegram bot), **хаанаас ч товчлолоор дуудах**, **дуугаар командлах**
8. **Үйлдлийн журнал**: TED-ийн хийсэн бүхнийг харж, мөр бүрийг буцаана. **Холболтын эрүүл мэнд**-ийг хянана
9. Таны засваруудаас **суралцаж**, бичих хэв маягийг тань дуурайна

> **Аюулгүй байдлын зарчим:** хариу мэйл, мессеж **хэзээ ч автоматаар явахгүй** — та "Илгээх" (эсвэл Telegram-д "✅ Тийм, илгээ") дарж байж л явна.

## 1. Суулгах

1. **`TerreSystem-Setup-1.0.0.exe`**-ийг ажиллуулна. Python тусад нь суулгах шаардлагагүй, бүх зүйл дотроо байгаа.
   - Windows "Windows protected your PC" гэж анхааруулбал → **More info → Run anyway** (гарын үсэггүй програм тул)
   - `C:\Program Files\Terre System`-д суух ба Эхлэх цэс, ширээний товч, "Windows асахад асаах" сонголт үүснэ
2. Суулгаж дуусахад TED асна. Анх **ДЕМО** горимоор ажилладаг тул шууд туршиж үзэж болно.
3. Tray (цагны хажуу) дахь цэнхэр дугуй икон дээр баруун товч → цэс:
   **Самбар нээх · Тушаал өгөх · Дуугаар ярих · Тохиргоо засах · Холболт тохируулах · Хаах**

Тохиргоо, өгөгдөл: **`%APPDATA%\Terre System\`** (`config.yaml`, `data\`). Устгахдаа хадгалах эсэхийг асууна.

### Анхны тохиргоо (10 минут)
1. Эхлэх цэс → **"TED — холболт тохируулах"**: нэр, **Gemini API түлхүүр**-ийг асууж хадгална
   (https://aistudio.google.com/apikey → *Create API key*)
2. Tray → **Тохиргоо засах** (`config.yaml`): хэрэгтэй холболтуудаа `enabled: true` болгоно (доорх 3-р хэсэг)
3. Дахин **"холболт тохируулах"**-ыг ажиллуулж нэвтэрнэ → төгсгөлд "Демо горимоос гарах уу?" → **y**
4. Tray → Хаах → Эхлэх цэснээс дахин асаана

### Товчлол
| Товч | Үйлдэл |
|---|---|
| **Win + Shift + T** | Аль ч програм дээрээс жижиг тушаалын цонх |
| **Win + Shift + V** | Шууд дуугаар ярих (микрофон) |

Өөрчлөх: `config.yaml` → `desktop:`. Өөр програм тэр товчийг ашиглаж байвал "Систем" табд анхааруулга гарна.

## 3. Холболтууд

Идэвхжүүлэх эх сурвалж бүрийг `config.yaml` дээр `enabled: true` болгоод, доорх алхмыг хийнэ.
Эцэст нь **`setup_connections.bat`**-ийг ажиллуулж нэг удаа нэвтэрнэ.

### 3.1 Gmail + Google Calendar (+ Google Chat)
1. https://console.cloud.google.com → шинэ project үүсгэнэ (жишээ нь "Terre System")
2. **APIs & Services → Library**: `Gmail API`, `Google Calendar API`-г Enable хийнэ
   (Google Chat бол `Google Chat API`-г ч Enable хийгээд, түүний **Configuration** хуудсанд нэр, icon бөглөнө)
3. **OAuth consent screen**:
   - Сургуулийн Google Workspace данс бол → **Internal**
   - Хувийн @gmail.com бол → **External**, *Test users* хэсэгт өөрийн мэйлийг нэмнэ
   - ⚠️ External + "Testing" төлөвтэй бол нэвтрэлт **7 хоногт** дуусдаг. Үүнээс сэргийлэхийн тулд **Publish app** дарна
     (баталгаажаагүй app гэсэн анхааруулга гарна. Өөрөө хэрэглэх бол асуудалгүй, *Advanced → Go to TED* дарна)
4. **Credentials → Create credentials → OAuth client ID → Desktop app** → JSON татаж аваад
   `secrets\google_credentials.json` нэрээр хадгална

> Google Chat API зөвхөн **Google Workspace** (байгууллагын) данс дээр ажиллана. Хувийн Gmail-д ажиллахгүй.

### 3.2 Outlook / Microsoft 365
1. https://portal.azure.com → **App registrations → New registration**
   - Supported account types: *Accounts in any organizational directory and personal Microsoft accounts*
2. **Authentication → Allow public client flows = Yes**
3. **API permissions → Microsoft Graph → Delegated**: `Mail.ReadWrite`, `Mail.Send`, `Calendars.ReadWrite`
4. **Overview**-оос *Application (client) ID*-г хуулж `config.yaml` → `outlook: client_id`-д тавина

> Сургуулийн M365 данс бол IT админ "admin consent" өгөх шаардлагатай байж магадгүй.

### 3.3 Бусад мэйл хаягууд (сургуулийн домэйн, Yahoo, iCloud, Mail.ru...)

IMAP/SMTP дэмждэг ямар ч мэйлийг нэмж болно, хэдийг ч хамаагүй. `config.yaml` → `other_mail:` жагсаалтад нэмнэ:

```yaml
  other_mail:
    - name: "Сургуулийн мэйл"        # самбарт ингэж харагдана
      enabled: true
      email: "tuvshuu@school.edu.mn"
      imap_host: "mail.school.edu.mn"
      smtp_host: "mail.school.edu.mn"
    - name: "Yahoo"
      enabled: true
      provider: yahoo                 # сервер, портыг автоматаар бөглөнө
      email: "you@yahoo.com"
```

- `provider` бэлэн байгаа: `yahoo`, `icloud`, `mailru`, `yandex`, `zoho`, `aol`, `gmx`
- Сургуулийн/байгууллагын домэйн мэйл бол IMAP, SMTP серверийн хаягийг hosting эсвэл IT-аас асууна
  (ихэвчлэн `mail.<домэйн>`, порт 993 / 465). Тэр мэйлийн тохиргоонд IMAP идэвхтэй байх ёстой.
- Нууц үгийг `config.yaml`-д **бичихгүй**. `setup_connections.bat` асууж, шалгаад
  **Windows Credential Manager**-т хадгална.
- Yahoo, iCloud, AOL, Yandex, Mail.ru, Zoho нь энгийн нууц үгээр гаднаас нэвтрэхийг хориглодог.
  Дансны аюулгүй байдлын тохиргооноос **App password** үүсгээд түүнийг оруулна.
- Gmail, Outlook-той адил: уншихдаа "уншсан" болгохгүй, хариуг таны зөвшөөрлөөр илгээж, "Илгээсэн" хавтсанд хуулбар хадгална.
  Хавсралтыг татаж ангилна, спамыг архивлана (`archive_folder`).
- Календарь IMAP-аар дамждаггүй. Тиймээс эдгээр дансны календарь самбарт орохгүй.

### 3.4 Telegram
1. https://my.telegram.org → **API development tools** → app үүсгэнэ
2. `api_id`, `api_hash`-ийг `config.yaml`-д хуулна
3. `setup_connections.bat` утасны дугаар болон Telegram-д ирсэн кодыг асууна

> Messenger, Viber-т хувийн дансны албан ёсны API байхгүй тул холбох боломжгүй.

### 3.5 School Manager (Lite)

TED таны School Manager **Lite** програмтай **TED Bridge**-ээр шууд холбогдоно. Товч дарах, цонх таних зүйл байхгүй.
Тушаал програмын дотор талд очиж, програмын өөрийн хадгалалтын логикоор (таны сонгосон өгөгдлийн хавтаст) хадгалагдана.

**Хэрхэн ажилладаг вэ (Lite / Neutralino):** Lite-д Electron шиг Node процесс байхгүй тул холболт нь файлын
"шуудангийн хайрцаг" юм:
- School Manager асахад `%APPDATA%\TerreBridge\school-manager.json`-д нууц token бичиж, 5 секунд тутам "heartbeat" шинэчилнэ.
- TED тушаалаа `%APPDATA%\TerreBridge\school-manager\inbox\`-д бичнэ → School Manager 1 секунд тутам шалгаж гүйцэтгээд
  хариуг `outbox\`-д бичнэ. Цонх жижигрүүлсэн (minimized) үед ч ажиллана.
- Сүлжээний порт нээхгүй, нэмэлт програм хэрэггүй, `neutralino.config.json`-д өөрчлөлт байхгүй.
- School Manager хаалттай үед TED өгөгдлийн файлаас (`sm-data-mirror.json`) самбарын тоог **зөвхөн уншина**.

**1. School Manager-т TED Bridge нэмэх (нэг удаа)**

GitHub дээр `btuvshinbayar-wq/school-manager` repo-ийн **`terre-bridge-lite`** салбарт бэлэн байгаа. `main`-д нэгтгээд
(эсвэл `school-manager-terre-bridge.patch`-ийг `git am`-ээр хэрэглээд) ердийнхөөрөө Lite installer хийнэ:
```
cd school-manager
git checkout main && git merge terre-bridge-lite      (эсвэл: git am school-manager-terre-bridge.patch)
build-neutralino.bat
```
Өөрчлөлт: `src/utils/terreBridge.ts` (шинэ), `App.tsx`, Тайлан/Ирц/Нэгтгэл/Хөтөлбөрийн дэлгэцэд хэдэн мөр,
`neutralinoBridge.ts` (TED-ийн экспортыг "Хадгалах" цонхгүй заасан зам руу бичих).
Лицензийн систем, машины ID-д огт хүрээгүй. Лиценз идэвхжээгүй үед bridge ямар ч өөрчлөлт хүлээж авахгүй.

**2. TED-ийн тохиргоо:** `config.yaml` → `school_manager:`
- `enabled: true` (анхдагч)
- `exe:` хоосон бол `C:\Program Files\SchoolManager\SchoolManager.exe`-г автоматаар олно
- `data_dir:` хоосон бол програмын сонгосон хавтсыг өөрөө олно (`data-location.json`). Жишээ: `'D:\work\2026-2027\SchoolManager-Data'`

**TED-ээр хийж болох зүйлс** (самбарын «Ажил» таб → ⚙ School Manager, бүлгээр):

| Бүлэг | Тушаал | Жишээ (тушаалын мөрөнд бичих) |
|---|---|---|
| Ирц & цаг | Багшийн ирц тэмдэглэх (шалтгаан, хоцорсон минут, ороогүй цагтай) | *"[багшийн нэр] багшийг өнөөдөр өвчтэй гэж тэмдэглэ"* |
| | Бүгд ирсэн гэж бүртгэх | *"Өнөөдөр бусад нь бүгд ирсэн"* |
| | Сарын нэмэлт цаг оруулах (орлон, илүү цаг, өмнөх сарын зөрүү) | *"[багшийн нэр] 11-р сард 4 цаг орлон заасан"* |
| | Цагийн тооцоо (Excel) — дэлгэцийн тооцоотой яг ижил | *"11-р сарын цагийн тооцоо гарга"* |
| | Сарын цагийн тооцоо хаах / хаалт цуцлах | *"11-р сарыг 25-ны өдрөөр хаа"* |
| Тэмдэглэл & төлөвлөгөө | Ажлын тэмдэглэл нэмэх, Төлөвлөгөө нэмэх, Төлөв солих, Төлөвлөгөө (Excel) | *"20-нд заах аргын семинар төлөвлөгөөнд нэм"* |
| Тайлан | Нэгдсэн ажлын тайлан — сар/7 хоног/улирал/жил, Word/PDF/PowerPoint | *"Энэ сарын тайланг PDF-ээр гарга"* |
| Хөтөлбөр & ажиглалт | Төлөвлөгөөний файл шинжлэх (Word/PDF-ийг шинжилгээний цонхонд ачаална) | *"Мэйлээр ирсэн нэгж төлөвлөгөөг шинжил"* |
| | Хөтөлбөр импортлох, Хөтөлбөрийн шинжилгээ (Word), Ажиглалтын хуудас (Word), Давтагдсан сул тал (Word), Ажиглалтын хуудас нээх | |
| Нэгтгэл | Өөрийн тайлангийн багц (.json), Менежерүүдийн тайлан нэгтгэх (бусад .json файлуудаас) | |
| Тохиргоо & нөөц | Амралтын өдөр нэмэх, Бүрэн нөөцлөл (өдөр бүр 17:30), Багшийн хуваарь (JSON), Цонх нээх | |

- Файлууд `Documents\Terre\Тайлан\`, `Documents\Terre\Нөөцлөл\` хавтаст очно. PDF-ийг TED Microsoft Word-оор
  Word файлаас хөрвүүлнэ (Word файл ч үлдэнэ).
- **AI шинжилгээ ба хадгалах шийдвэр таных:** "Төлөвлөгөөний файл шинжлэх", "Хөтөлбөр импортлох" нь файлыг School Manager-ийн
  цонхонд ачаалж өгнө — «Шинжилгээ», «Хадгалах» товчийг та өөрөө дарна.
- TED тушаалыг ойлгоод маягт бөглөж харуулна, та **▶ Ажиллуулах** дарж байж л School Manager-т хийгдэнэ.
  School Manager дээр "🤖 TED: …" гэсэн мэдэгдэл гарна. Ирц, тэмдэглэл, төлөвлөгөө, сарын цаг, амралтын өдөр, сарын хаалт —
  бүгдийг журналаас буцааж болно. TED таны өгөгдлийг устгадаггүй (зөвхөн өөрийн нэмсэн бичлэгийг буцаах үед хасна).
- Самбарын тоонууд, санал болгох жагсаалт (багш, төлөвлөгөө, хөтөлбөр, ажиглалт) нь зөвхөн таны **жинхэнэ өгөгдлөөс** гарна.
  Демо горимд School Manager-ийн зохиомол өгөгдөл харуулахгүй.

School Manager хаалттай бол самбарт **Хаалттай · файлаас** гэж гарч, тоонуудыг өгөгдлийн файлаас харуулна. **Нээх** товч эсвэл
тушаал өгөхөд TED програмыг автоматаар асаана. `open_at_startup: true` болговол TED асахад School Manager-ийг ч асаана.

### 3.6 Файл эмхлэгч

`config.yaml` → `files:` хэсэг. Анхдагчаар асаалттай.

- **Мэйлийн хавсралт**: хариу шаардсан, яаралтай мэйлүүдийн хавсралтыг `Documents\Terre\_Ирсэн`-д татаад ангилна.
  Спам гэж ангилсан мэйлийн хавсралт, мөн `.exe`, `.bat`, `.js` зэрэг аюултай төрлийн файлыг татахгүй.
- **Downloads, Desktop, Documents-ийг TED өөрөө цэгцлэхгүй.** Цэгцлэх хавтсаа самбарын «Файл» таб →
  **📁 Холбосон хавтсууд**-аас зааж тохируулна (3.7). Өмнөх хувилбар Downloads-аас зөөсөн файлуудыг «🗂 Файлууд»
  хэсгийн **↶ Бүгдийг буцаах** товчоор анхны газар, анхны нэрээр нь буцаана.
- Ангилал нь **агуулгаар** хийгдэнэ: Gemini PDF, Word, Excel, текст файлын эхний хэсгийг уншаад
  `Тайлан`, `Тушаал, шийдвэр`, `Албан бичиг`… гэх мэт ангилалд хуваарилна. Ангиллын жагсаалтыг `categories`-д өөрчилж болно.
- Файлыг **хэзээ ч устгахгүй**. Зөвхөн зөөнө, самбараас **↶ Буцаах** дарж анхны газарт нь буцаана.
- Анх асаахад `since_days`-ээс (30 хоног) хуучин файлд хүрэхгүй. Татаж дуусаагүй файлд хүрэхгүй.

**Файлын нэр солих** (`files.rename`):
- `scan0001.pdf`, `IMG_1234.jpg`, `Document (3).docx`, `download.xlsx` гэх мэт **утгагүй нэрийг** агуулгаар нь сольно:
  `scan0001.pdf` → `БГ-ын А-215 албан бичиг багшийн сургалт.pdf`. Аль хэдийн тодорхой нэртэй файлд хүрэхгүй (`only_messy`)
- **Мэйлийн хавсралт** илгээгч, огноотой нэрлэгдэнэ: `2026-11-15 Боловсролын газар - Ирцийн маягт.xlsx` (`attachment_template`)
- Самбарт шинэ нэр харагдах ба зөөхөөс өмнө **засаж болно**. Буцаахад анхны нэр нь сэргэнэ
- Нэрийг Gemini **ангилах дуудлагатай хамт** гаргадаг тул нэмэлт зардал бараг гарахгүй. `use_ai: false` болговол
  токенгүйгээр "Ангилал + огноо" хэлбэрээр нэрлэнэ

### 3.7 Компьютер дээрх хавтсуудыг холбож цэгцлэх

Самбарын **📁 Холбосон хавтсууд** хэсгээс дурын хавтсыг холбоно: **＋ Хавтас сонгох** (Windows-ийн сонгох цонх нээгдэнэ)
эсвэл замыг бичиж **Холбох**. Хэдэн хавтас ч холбож болно, жишээ нь `D:\Сургууль`, `E:\Хуучин баримтууд`.

**✨ Цэгцлэх** дарахад:
1. TED хавтсыг (дэд хавтсуудыг оруулаад) судалж **төлөвлөгөө** гаргана. Энэ үед **юу ч хөдлөхгүй**.
   - Файл бүрийг агуулгаар нь ангилна (Gemini 20 файлыг нэг дор, хямд)
   - Яг ижил агуулгатай **давхардсан** файлыг олж `_Давхардсан` хавтас руу зөөхөөр төлөвлөнө (хамгийн хуучныг нь үлдээнэ)
   - Сонговол цэгцэлсний дараа **хоосорсон хавтсуудыг** устгана
2. Та тоо, ангилал тус бүрийн хэмжээг харж, хүсвэл файл бүрийн ангиллыг сольж эсвэл алгасна
3. **✓ Хэрэгжүүлэх** → цэгцэлнэ. Таалагдахгүй бол **↶ Бүгдийг буцаах** дарахад бүх файл анхны газартаа очно

Хавтас тус бүрийн тохиргоо:
- **Тухайн хавтас дотор цэгцлэх** (анхдагч): `D:\Сургууль\Тайлан\`, `D:\Сургууль\Тушаал, шийдвэр\`…
- **Documents\Terre руу зөөх**: бүх хавтсын файлыг нэг газар төвлөрүүлнэ
- **Шинэ файлыг хянах**: хянахгүй / санал болгох / автоматаар. Цаашид тэр хавтсанд орж ирсэн шинэ файлыг ангилна

Аюулгүй байдал:
- Файлыг **хэзээ ч устгахгүй**, зөвхөн зөөнө. Давхардсан файл ч `_Давхардсан` руу очно, тэндээс та өөрөө шийднэ
- Програмын код агуулсан хавтсанд (`.git`, `package.json`, `node_modules`…) огт хүрэхгүй
- `C:\` бүтнээр, Windows, Program Files, AppData, хэрэглэгчийн үндсэн хавтсыг холбох боломжгүй
- Нээлттэй (Word-д нээгдсэн гэх мэт) файлыг алгасаж, алдааны тоонд харуулна

### 3.10 «Хэй Тэд» гэж дуудаж тушаал өгөх (утасны Siri шиг)

TED-ийг нэрээр нь дуудахад реактор гэрэлтэж «дин» дуу гарна → тушаалаа хэлнэ → TED ойлгоод биелүүлж, юу хийснээ дуугаар хэлнэ.
Жишээ: *«Хэй Тэд… өнөөдөр 2 цаг багш нартай уулзалт хийсэн гэж тэмдэглэ»*, *«Хэй Тэд… Ажил 1-ийг биелсэн болго»*.

- **Нууцлал:** «Хэй Тэд» гэж дуудахаас өмнө TED ямар ч яриа бичихгүй, хадгалахгүй, хаашаа ч илгээхгүй. Дуудах үг таних хэсэг
  (Vosk) компьютер дээрээ, интернэтгүй ажиллаж, зөвхөн «hey ted» гэсэн хоёр үгийг л таньж чаддаг (бусад яриаг текст болгох
  чадваргүй) — ирж буй дууг тэр дор нь шалгаад хаядаг. Бичлэг зөвхөн «дин» дууны дараа эхэлж, тэр тушаал л Gemini-д очно.
  «Хэй Тэд»-ийг **тусдаа, тод** хэлэх ёстой (өмнө нь өөр үг залгаж ярьвал тоохгүй). Дуудагдсаны дараах яриа тушаал биш
  (утсаар ярьж буй яриа г.м.) бол юу ч бичихгүй, хэлэхгүй, хаяна.
  Утсаар ярих үед самбарын дээд хэсгийн **🎧** товчийг дарж түр зогсооно (🔇). Огт хэрэглэхгүй бол `voice: wake: enabled: false`.
- Бүрэн ойлгосон School Manager-ийн тушаалыг шууд биелүүлнэ (журналаас буцаана). Мэдээлэл дутуу бол самбар дээр маягт нээгдэж,
  юу дутуу байгааг дуугаар хэлнэ. Мэйл, мессежийг дуугаар **хэзээ ч илгээхгүй**.
- Монгол хэлэнд «тэд» гэдэг өдөр тутмын үг тул ганцаараа дуудах үг болгоогүй — **«Хэй Тэд»** гэж хоёр үгээр дуудна.

Асаах (нэг удаа):
1. Админ PowerShell: `& "C:\Program Files\Terre System\python\python.exe" -m pip install vosk sounddevice`
   (`No module named pip` гэвэл эхлээд `... python.exe -m ensurepip` ажиллуулна)
2. `config.yaml` → `voice:` дотор `wake: enabled: true` (`auto_run: false` болговол үргэлж самбар дээр баталгаажуулна)
3. TED-ийг дахин асаана. Анх асаахад ≈40 MB загварыг өөрөө татна. «Систем» таб → «Дуудах үг» мөрөнд төлөв харагдана.

### 3.11 Мэйл шалгах, Google Meet уулзалт, Google Drive (тушаалаар, дуугаар)

«Ажил» таб → тушаалууд (эсвэл «Хэй Тэд…»): **Мэйл шалгах**, **Уулзалт товлох (Google Meet)**, **Drive-д файл байршуулах**,
**Drive-оос файл татах** (`Documents\Terre\Drive`), **Drive файл хуваалцах**, **Drive-оос файл хайх**.
Бусдад мэдэгдэл очдог тушаалыг (оролцогчтой уулзалт, хуваалцах) дуугаар хэлсэн ч самбар дээр та ▶ Ажиллуулах дарж байж хийгдэнэ.
Уулзалт, байршуулсан файл, хуваалцалтыг журналаас буцаана.

Drive асаах (нэг удаа):
1. Google Cloud Console (TED-ийн project) → хайлтаас **Google Drive API** → **Enable**
2. `config.yaml` → `sources:` дотор `google_drive: enabled: true`
3. Эхлэх цэс → «холболт тохируулах» → Google-д дахин нэвтэрч **Allow** (Drive-ийн эрх нэмэгдэнэ).
   Дахин нэвтрэхээс өмнө Gmail «эрх нэмэгдсэн» гэж түр зогсоно.

### 3.12 Англи хэл (англиар мэдээлэх)

`config.yaml` → `language: "en"` (анхдагч) үед TED таньд **англиар** мэдээлнэ: «Good morning, Sir», өдрийн мэдээ, мэйлийн
товч агуулга, тушаалын хариу, анхааруулга, самбарын бичиг, хоолой (`en-GB-RyanNeural`). Монгол руу буцаах бол `language: "mn"`.
- **Тушаалыг англиар эсвэл монголоор** өгч болно. Мэйлийн **хариу ноорог** ирсэн мэйлийн хэлээрээ үлдэнэ (монгол мэйлд монголоор).
- School Manager-т бичигдэх утга (багшийн нэр, ирцийн төлөв, ангилал) монголоор хэвээр; самбар дээр «Sick · Өвчтэй» гэж хоёр хэлээр харагдана.
- **API-гүй англи:** англиар хэлсэн тушаалыг компьютер дээрээ (Vosk) текст болгоно — интернэт, токен хэрэггүй. `vosk` суусан
  байх ёстой (3.10-ын 1-р алхам). Тод бус эсвэл монголоор хэлсэн бол Gemini-ээр таниулна. Англи хоолой ч API түлхүүргүй (Edge TTS).
  Тушаалыг ойлгох (аль тушаал, ямар багш) хэсэг Gemini-тэй үед илүү ухаалаг; түлхүүргүй үед энгийн түлхүүр үгээр (check mail,
  mark … as sick, meeting, timesheet, backup …) таньна.

### 3.13 Хоёр дахь (өөр) Google данс нэмэх

Үндсэн Google данс (Gmail + Calendar + Drive) нэг байна. Нэмэлт Gmail дансыг «бусад мэйл»-ээр (IMAP) холбоно:
1. Нэмэх дансаараа https://myaccount.google.com/security → **2-Step Verification** асаана.
2. https://myaccount.google.com/apppasswords → нэр «TED» → гарсан 16 тэмдэгтийг хуулна.
3. `config.yaml` → `sources: other_mail:` хэсэгт:
   ```yaml
       - name: "Gmail 2"
         enabled: true
         provider: gmail
         email: "таны.хоёр.дахь@gmail.com"
   ```
4. Эхлэх цэс → «Terre — холболт тохируулах» → тухайн данс дээр App password-ийг буулгана (Windows Credential Manager-т хадгална).
5. TED-ийг дахин асаана. Мэйл нь самбарт «Gmail 2» гэсэн эх сурвалжтай гарна; хариуг тухайн дансаас илгээнэ.
Анхаар: энэ замаар зөвхөн **мэйл** холбогдоно (хоёр дахь дансны календарь/Drive биш).

### 3.14 Viber, Discord, Messenger, Google Chat

Эдгээрийн хувийн чатыг унших албан ёсны API байхгүй тул TED **Windows-ийн мэдэгдлийг** уншина (таны профайл дахь
мэдэгдлийн сангийн хуулбарыг, зөвхөн уншина — дансанд нэвтрэхгүй, дүрэм зөрчихгүй).
1. `config.yaml` → `sources: app_notifications: enabled: true` (`apps: [viber, discord, messenger]`).
2. **Viber, Discord** (компьютерийн апп): Тохиргоо → Notifications асаалттай, мессежийн **preview (агуулга харуулах)** асаалттай.
3. **Messenger** (браузер): messenger.com-ыг нээгээд хаягийн мөрний 🔒 → **Notifications → Allow**. Браузер нээлттэй байх ёстой.
4. Windows Тохиргоо → System → Notifications дээр тухайн апп/браузерын мэдэгдэл асаалттай байна.
5. TED-ийг дахин асаана. Мессеж самбарт «Viber / Discord / Messenger» гэж гарч, TED ангилж, ноорог бичнэ.
**Хариу:** «📋 Copy & open Viber» дарахад ноорог хуулагдаж, программ нээгдэнэ → чатаа сонгоод **Ctrl+V → Enter**.
TED өөрөө хэзээ ч илгээхгүй. Хязгаарлалт: мэдэгдэлд харагдсан текст л ирнэ (урт мессежийн эхний хэсэг, зураг ирэхгүй);
утсаараа уншсан мессеж компьютерт мэдэгдэл болж ирэхгүй байж болно.

**Google Chat** (moes.edu.mn, үндсэн данс солихгүйгээр): chat.google.com → ⚙ → **Email notifications** асаана.
Уншаагүй Chat мессежийн мэдэгдлийн мэйл «Gmail 2»-оор ирж, самбарт «Google Chat» гэж гарна. Хариу нь мөн «Copy & open Google Chat».

## 4. Шинэ боломжууд (самбарын табууд)

**Нүүр** — ар талд маш бүдэг ногоон код урсана. TED-тэй харилцах үед (бичих, 🎙, «Hey Ted», TED ярих) урсдаг кодоор бүтсэн
нарийвчилсан 3D хүний толгой тодорч гарна: сонсоход нүд гэрэлтэж, ярихад ам хөдөлж, бодох үед алтан код гүйнэ, харилцаа дууснаас
9 секундын дараа бүдгэрнэ. 3D толгой: three.js + «Face Cap» загвар (bannaflak.com/face-cap, three.js-ийн жишээ загвар) —
`web/assets/ted-head.js` / `.glb`, эх код `web/src/head.js`.
**Өөрийн зураг TED болох:** Систем таб → «🧙 TED's look» → 📷 Choose picture → зураг дээр савааны үзүүрийг нэг дарна.
Зураг зөвхөн энэ компьютерт (`%APPDATA%\Terre System\data\avatar.*`) хадгалагдана. Харилцах үед зураг код дотроос алхаж
гарч ирж, «Lumos» бичигтэй савааны гэрэл асна; ярихад гэрэл дууны хэмнэлээр, сонсоход тод, бодоход анивчина.
Төвд TED-тэй **ярилцах хэсэг** (асуулт, хариулт; бичих эсвэл 🎙), доод мөрөнд **Chats** (Viber, Messenger, Discord, Google Chat — мэйлийн жагсаалтаас тусдаа; дарахад хариу бичих хэсэг нээгдэнэ). TED-ийн ард огторгуй (анивчих од, мананцар, удаан эргэх галактик, хааяа унах од). Баруун талд **Open issues** (яаралтай, таны зөвшөөрөл хүлээж буй, School Manager-ийн өнөөдрийн/хоцорсон ажил, хугацаа хэтэрсэн даалгавар) ба **Resolved** (TED шийдсэн, илгээсэн/алгассан, хийсэн даалгавар) жагсаалт — мөр дээр дарахад дэлгэрэнгүй нээгдэнэ.
Зүүн дээд буланд цаг, мэндчилгээ, өдрийн мэдээ; дээд төвд «Hey Ted» төлөв; доод төвд дуут самбар (🎙 ярих, 🔊 мэдээ сонсох, ↻ шинэчлэх).

**Ажил**
- **⚙ School Manager** — тушаал бичих эсвэл 🎙 дарж ярих
- **✅ Даалгавар, хугацаа** — мэйлээс автоматаар үүссэн даалгавар (хугацаатай), "⏳ хариу хүлээж байна" (TED-ээр илгээсэн
  хариунд 3 хоногт хариу ирэхгүй бол; хариу ирвэл өөрөө хаагдана), **📅 хурлын урилга → "Календарьт нэмэх"**
- **📝 Өдрийн тайлан** — 17:00-д (эсвэл "Одоо бэлдэх") өнөөдрийн хурал, илгээсэн хариу, хийсэн ажлаас тэмдэглэлийн
  ноорог; гарчиг, ангилал, цагийг засаад **"School Manager-т оруулах"**

**Файл** — 🔎 **Файлаас хайх, асуух** (хайлт токенгүй; "✨ Асуух" үед л Gemini), 🗂 файлууд, 📁 холбосон хавтсууд.

**Систем**
- **🩺 Холболтын эрүүл мэнд** — холболт бүрийн төлөв, сүүлд амжилттай шалгасан цаг, алдаа гарвал **юу хийхийг** зааж өгнө
  (Gmail-ийн 7 хоногийн нэвтрэлт дуусахаас өмнө анхааруулна). Табын хажуугийн цэг ногоон/шар/улаан болно
- **📜 Үйлдлийн журнал** — архивласан мэйл, зөөсөн файл, School Manager-т оруулсан ирц, нэмсэн календарь... мөр бүрийг **↶ Буцаах**
  (илгээсэн мэйлийг л буцаах боломжгүй)
- **🧠 Сурсан зүйл** — ангиллыг засах бүрт TED дараа нь ижил төрлийнхийг тэгж ангилна; 5 ноорог засаж илгээхэд
  **бичих хэв маягийн профайл** үүснэ (засаж, устгаж болно)
- Тохиргоо засах, холболт тохируулах, дахин асаах, **демо горимоос гарах** товчнууд

**Аюулгүй байдал:** самбар зөвхөн TED-ийн нээсэн цонхонд ажиллана (нууц токен). Нууц үг, token-ууд Windows Credential Manager-т.

| Товчлол ажиллахгүй | "Систем" табд товчлолын анхааруулга байгаа эсэхийг харж, `desktop:`-д өөр товч тохируулна |
| Дуу гарахгүй | Дуу (edge-tts) интернэт шаарддаг. `voice: enabled` шалгана |
| Google "access blocked" | OAuth consent screen-д өөрийгөө Test user болгож нэмсэн эсэхээ шалгана |
| "School Manager хаалттай" гэсээр байна | TED Bridge-тэй шинэ Lite хувилбарыг суулгасан эсэхийг шалгана. `%APPDATA%\TerreBridge\school-manager.json` үүсэж, `heartbeat` нь шинэчлэгдэж байх ёстой. Лицензийн цонх нээлттэй бол хариу өгөхгүй |
| "лиценз идэвхжээгүй" | School Manager-ийн лицензийг идэвхжүүлнэ |
| Бусад мэйл "authentication failed" | App password хэрэгтэй эсэх, IMAP идэвхтэй эсэхийг шалгаад `setup_connections.bat`-аар нууц үгээ дахин оруулна |
| Архивлахгүй байна | Сервер дээрх архивын хавтсын нэрийг `archive_folder`-д бичнэ (жишээ нь `INBOX.Archive`) |
| Port завгүй | `config.yaml` → `server: port`-г солино |
